Kích hoạt Đồng bộ Real-time (Firebase)

Để tự lưu trữ và đồng bộ dữ liệu thời gian thực trên hosting cá nhân (Netlify / Vercel / GitHub Pages):

  1. Tạo dự án miễn phí tại console.firebase.google.com.
  2. Bật Authentication → Anonymous và khởi tạo Firestore Database.
  3. Sao chép đối tượng firebaseConfig trong mục Project Settings.
  4. Mở tệp index.html và dán vào biến USER_FIREBASE_CONFIG.
Mẹo: Bạn vẫn có thể trải nghiệm toàn bộ tính năng (kéo-thả, cảnh báo trùng giờ, to-do, xuất/nhập JSON) ngay bây giờ ở chế độ cục bộ!
